- **Chunked stream framing (`encryptStream`/`decryptStream`) authenticates both chunk position and stream completeness.** Initially shipped with only index-bound AAD (stops reordering/swapping) and no anti-truncation check — flagged as a known gap in README.md rather than silently left out, since the plan's T-07b DoD list didn't explicitly ask for it. Closed immediately after: each chunk's AAD now also carries a 1-byte `isFinal` flag, and both `encryptStream` and `decryptStream` use a one-chunk lookahead (peek at `iterator.next()` before yielding/decrypting the current chunk) to know whether the current chunk is genuinely the last one. A transport that drops the true final chunk(s) makes the last-arriving chunk get decrypted as if `isFinal=true`, but it was encrypted with `isFinal=false` — GCM authentication fails, so truncation surfaces as a thrown error instead of silently short plaintext.
