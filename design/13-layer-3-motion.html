Meridian V2 · Layer 3 · Implementation review

Motion tokens and the constitution guardrail

Three tiers decided by consequence, a set of utilities components reach for instead of inventing a fourth tempo, and an author-time lint rule so the ban cannot erode.

What changed

  • Four motion utilities — .motion-instant, .motion-considered, .motion-approach, .motion-record-arrive. Components reach for a tier rather than composing transition duration-X ease-Y by hand, which is how a fourth unowned tempo gets invented.
  • The three banned animations are gone. Skeleton no longer pulses, StateChip no longer pulses on unlocked, and Button no longer renders a spinner.
  • A CSS backstop neutralises animate-spin/ping/bounce even if it arrives through a dependency's own stylesheet.
  • A global reduced-motion rule collapses every transition and keyframe — while deliberately leaving --motion-hold and --motion-empty-frame untouched, because the silences are timing rather than motion and carry the meaning.
  • A shared ESLint rule (@tc/eslint-config/motion) fails the build on banned animation classes and on any cubic-bezier with a control point outside [0,1].

Implementation decisions

  • The loading button keeps its label. V1 replaced children with a spinning ring, which both violated the spinner ban and stripped the button of its accessible name for exactly as long as the user most needed it. V2 keeps the label, disables the control and sets aria-busy — state carried in text and semantics, never in motion (design/07 §V.4).
  • The lint rule lives in a shared module, not duplicated. apps/web uses eslint-config-next and does not extend base.js, so the rule would have been silently absent from the one package where almost all UI is authored. Extracted to motion.js and imported by both.
  • The held beat is not a CSS utility. .motion-approach covers the constant-velocity approach only. A dead stop followed by an instant state change cannot be expressed as a CSS transition, so the stop is orchestrated in JS — as Gate 1 proved out with a single timeline scalar.
  • Skeleton is now aria-hidden. It reserves space and nothing else; announcing a placeholder to a screen reader is noise.

The three tiers, live

Running the real token values. Duration is a function of consequence, never of aesthetics — if you can undo it, it is instant; if you cannot, it is held.

Instant

120ms · cubic-bezier(.2,0,0,1)

Reversible. Navigation, settings, typing, toggles, hover.

Considered

240ms · cubic-bezier(.2,0,0,1)

Changes what you are looking at. Opening a capsule, entering the composer.

Held

900ms linear → 400ms stop → step

Irreversible. Seal, transit, reveal, permanent delete.

idle

Watch the held tier stop. The marker travels at constant velocity — never easing out, because easing out anticipates arrival and the point is that arrival is not yet — then holds completely still for 400ms before the state changes instantly. That stop is the signature, and it is the beat most likely to be “fixed” by someone who thinks the page has frozen.

Issues discovered

  • The lint rule initially did not fire on overshoot easing. My first regex only inspected the final coefficient, so cubic-bezier(.34, 1.56, 0.64, 1) passed. Rewritten with lookbehinds to catch any control point outside [0,1], then verified in both directions — it rejects the three overshoot forms and accepts the two real V2 easings.
  • The rule was not reaching apps/web at all until @tc/eslint-config was added as a dependency there. Confirmed live by linting a deliberate violation, rather than trusting a green run.
  • Carried, not yet fixed: Button's primary variant still measures 1.54:1 — brass fill with text-foreground. The --color-on-accent token exists and measures 10.23 dark / 6.07 light; the component consumes it at layer 4.

Inherited automatically

  • Every button in the app picked up the instant tier and lost the spinner with no call-site changes.
  • Every Skeleton and StateChip instance across all routes became static.
  • The reduced-motion guard applies to all current and future markup, including third-party components.

Remaining work

  • Layer 4 (primitives): the 1.54:1 button contrast; retire the deprecated --color-accent-violet focus ring in Input/OtpInput; audit destructive's white-on-danger.
  • Layer 4: a record-surface primitive. Nothing can be a record until one exists, so the serif half of Pairing C is still unproven.
  • Gate 2 (serif at density) is answerable once a real serif-led surface exists — better evidence than a specimen.
  • Bundle check: confirm font assets sit outside the 3 MiB Worker script limit with wrangler deploy --dry-run before T-21 consumes headroom.
